# PS3Xploit Resigner GUI

A Linux/Windows GUI for the PS3Xploit Resigner workflow — primarily the RAP-to-RIF flow that adds games to your own act.dat, producing a signed RIF-installer package for your PS3.

## Credits

- **PS3Xploit Resigner** — by the **PS3Xploit Team** (GPL-3.0, github.com/PS3Xploit/PS3xploit-resigner). The engine is theirs; this project is a graphical front end that carries the engine ready-built.
- Your act.dat, idps, and RAP files are per-console private material: the app reads them from your folders and never bundles, uploads, or shares them.
